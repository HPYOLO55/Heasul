Feature: AI Hairstyle Suggestions

Add a new feature called "AI Hairstyle Advisor" to the existing GlowUp AI app.

Goal

Allow users to upload or capture a selfie. The app should send the image to the Nemotron API and return personalized hairstyle recommendations based on visible facial features. The feature must not claim certainty or guarantee results. It should provide style suggestions only.

---

UI

Create a new page named Hairstyle Advisor.

Layout:

- Premium dark theme matching the app
- Large upload/camera button
- Image preview
- "Analyze Hairstyle" button
- Loading animation while AI is processing
- Beautiful result cards

---

Image Input

Allow users to:

- Capture a selfie
- Upload an existing image

Automatically:

- Compress the image
- Resize if needed
- Show preview before analysis

---

Gemini Vision Integration

Send the image to the Gemini Vision API.

Use the following instruction:

"You are a professional hairstylist.

Analyze the visible facial features and current hairstyle.

Provide hairstyle suggestions only.

Do not diagnose medical conditions or estimate attractiveness.

Return ONLY valid JSON.
