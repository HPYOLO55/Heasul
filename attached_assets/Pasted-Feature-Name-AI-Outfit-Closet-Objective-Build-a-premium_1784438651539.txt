Feature Name: AI Outfit Closet

Objective

Build a premium feature called AI Outfit Closet that lets users create a digital wardrobe by photographing their clothes. The AI should categorize garments, organize them, and generate outfit suggestions using only the items the user actually owns.

This feature should feel like a luxury wardrobe assistant rather than a simple gallery.

AI Clothing Analysis

Send the uploaded image to the vision model.

Prompt:

"You are a professional fashion stylist.

Analyze this clothing item.

Return ONLY valid JSON.

{
"name":"",
"category":"",
"subcategory":"",
"primary_color":"",
"secondary_colors":[],
"pattern":"",
"material":"",
"season":"",
"occasion":"",
"style":"",
"fit":"",
"gender":"",
"formality":"",
"description":"",
"confidence":""
}

Do not identify brands unless clearly visible.
Do not invent details.
Return only information supported by the image."
